# Anti-PD-L1 resistance in hepatocellular carcinoma

**Single-cell analysis · R · Seurat · SoupX · Manuscript in preparation**

This project forms part of my work on treatment resistance in cancer. The public excerpts show how I handled ambient RNA, doublet checks, normalization, clustering and marker-guided annotation. The study's experimental comparisons and biological findings remain unpublished.

## My analysis code

| Workflow | What the code shows |
| --- | --- |
| [Ambient RNA and doublet checks](../../workflows/ambient-rna-and-doublets.Rmd) | Raw/filtered droplet input, provisional Seurat clusters, SoupX correction, combining corrected samples and scDblFinder checks |
| [Normalization and clustering](../../workflows/sctransform-and-clustering.Rmd) | Log-normalization and SCTransform branches, PCA review, neighbor graphs, clustering and UMAP |
| [Broad annotation and composition](../../workflows/broad-annotation.Rmd) | Marker ranking, heatmaps, reviewed labels, composition summaries and subset preparation |

I use marker plots and dimensionality-reduction views to review the clustering before applying a biological annotation. The public code accepts a private annotation map in place of the original assignments. The numerical settings are retained as examples of my workflow and require review for a different dataset.
